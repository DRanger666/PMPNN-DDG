# Mutation / ΔΔG tables

Input tables for from-PDB extraction (`scripts/extract.py`). SHA256 hashes and
line counts: [MANIFEST.tsv](MANIFEST.tsv).

| Path | Dataset |
| --- | --- |
| `S_2648/S2648.txt` | S2648 train |
| `S_669/Data_s669_with_predictions.csv` | S669 test |
| `S_921/S921.txt` | S921 test |
| `Ssym/Ssym.txt` | Ssym test |

S2648, S921, and Ssym tables follow the PremPS distribution
([SajidAhmeduiu/PremPS](https://github.com/SajidAhmeduiu/PremPS)).
